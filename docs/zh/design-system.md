# Skill Base Web 视觉规范

参考 WeiBian 的内容优先设计，保留 Skill Base 顶部导航、绿色品牌和 CD 集合封面。

## 基础控件

- 主按钮浅色黑底白字、深色白底黑字；次按钮中性浅底；危险操作红字。
- 常规控件最小高度 40px、圆角 8px；登录输入与提交按钮 44px。hover 只改变颜色，不发光、不位移。
- 输入框使用主题底色与 1px 弱边框；聚焦使用绿色边框和柔和外圈，禁用态降低透明度。
- 普通界面使用 Inter 与系统中文字体，命令、路径、代码使用等宽字体。
- 颜色分别适配明暗主题；不复制 WeiBian 的紫色强调。

## 页面布局

- 列表、详情、对比及管理页最大 1280px；发布与设置最大 960px。
- 标题桌面 28px、移动端 24px。表单使用开放分区，弹窗用 12px 圆角。
- 集合列表与标题共用内容边界，CD 封面保留立体结构并减轻外围投影。
- 登录页为最大 960px 双栏面板；右侧使用本地 CD 组件展示产品特点。
- 820px 以下登录页采用最大 400px 单栏；640px 以下隐藏外框和阴影，输入字号 16px。

## 维护位置

- `web/src/assets/main.css`：主题变量、公共按钮。
- `web/src/assets/flat-forms.css`：表单、管理页和弹窗。
- `web/src/components/SkillBaseBrand.vue`：共享品牌。
- 文案在 `useI18n.ts` 中维护，登录逻辑及认证 API 不因视觉调整而改变。

## 验收

检查明暗主题、桌面和窄屏、中英文、键盘焦点、错误与禁用状态。构建使用 `npm run build --prefix web`，不要手改 static。

## 获取技能

默认提供 ZIP 下载和导入步骤，无需 Node.js 或 skb。AI Agent 提示词包含所选版本的 ZIP 直链；若助手无法访问站点或登录态，用户可通过浏览器下载并提供本地文件。命令行作为可选方式。公开下载免登录，私有下载保留权限边界；失败在页面显示，不打开 JSON 错误页。YAML description 按正文展示，不嵌套代码边框。
